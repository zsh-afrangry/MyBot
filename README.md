# Kurumi Fusion

个人维护的 QQ 助手扩展、配置意图与运维工具。日常源码目录为 `/home/afrangry/kurumi-fusion`，私有运行目录为 `/home/afrangry/.openclaw-fusion`，统一备份根为 `/home/afrangry/kurumi-backups`。

开始或继续工作前，先读唯一全局手册 [整理记录.md](/home/afrangry/.openclaw-fusion/整理记录.md)，按其中的当前目标、授权边界和继续位置执行。需求、整理及升级状态统一维护在该手册。

开发约束见 [AGENTS.md](AGENTS.md)，功能契约与验证入口见 [docs/README.md](docs/README.md)，配置部署见 [config/README.md](config/README.md)。运行目录中的身份、凭据和业务数据不进入源码仓库。KnowledgeMap 是外部独立项目，Fusion 通过接口使用其业务能力。
