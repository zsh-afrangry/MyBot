# 媒体渠道接入

## 进行中：媒体渠道接入

### 场景

- 希望助手能按关键词找媒体平台上的公开内容，也能读取主人发来的内容链接。首批考虑 B 站、X（推特）、小红书和抖音，优先做 B 站，优先选免费或有免费额度的方案。
- 初步设想是在 Fusion 中用一层配置管理各渠道的接入和启停。现有网页搜索和抓取见[检索功能](8_检索功能.md)。

### 初步调查

- B 站的大肥鱼仓库可访问。它是 MIT 许可的 DSH 插件，内置的 B 站 MCP 有关键词搜索、视频详情和字幕工具，可评估复用其中的只读部分。免登录能读到哪些内容待验证。[大肥鱼仓库](https://github.com/minedalang/dsh-dafeiyu-life) · [内置 B 站 MCP](https://github.com/minedalang/dsh-dafeiyu-life/tree/main/vendor/bilibili-mcp)
- X 的公开帖子链接可试用官方 oEmbed，样例已能返回嵌入内容。官方全站搜索按量计费。[oEmbed](https://docs.x.com/x-for-websites/oembed-api) · [X API 定价](https://docs.x.com/x-api/getting-started/pricing)
- 小红书有官方站内智能体能力，外部助手能否使用待确认。社区 MCP 支持搜索和详情，需要扫码登录。[小红书官方文档](https://miniapp.xiaohongshu.com/doc/DC897827) · [社区 MCP](https://github.com/xpzouying/xiaohongshu-mcp)
- 抖音官方关键词搜索需申请权限。第三方只读 MCP 提供少量免费预览。[抖音开放平台](https://open.douyin.com/platform/resource/docs/ability/search-management/video/) · [第三方 MCP](https://github.com/zen-studio-labs/douyin-mcp#pricing)

接手时再确认 B 站首版要支持哪些读取操作，并逐个核实各渠道的授权条件、免费额度和接入方式。
