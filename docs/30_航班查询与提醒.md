# 航班查询与提醒

## 进行中：航班查询与提醒

### 场景

- 做攻略时，按出发地、目的地和日期找合适的航班，返回航班号和计划起降时间。也可以用航班号和日期查具体航班。
- 接亲友时，告知助手航班后，希望在延误、开始登机和落地时收到 QQ 提醒。
- 自己出行时，希望收到出门和值机提醒。自动导入个人航班可选，也可以直接告诉助手日期、路线和大概时段，由助手匹配航班。固定时间提醒可考虑复用[个人提醒](3_个人提醒.md)。

优先考虑免费或有免费额度的来源。

### 初步调查

- 飞猪 FlyAI 支持按路线和日期查在售航班，可免 Key 试用。活动文案列出首次登录赠 5,000 次，实际额度待核。[官方 Skill](https://github.com/alibaba-flyai/flyai-skill/blob/main/README.zh-CN.md) · [飞猪 AI 开放平台](https://flyai.open.fliggy.com/docs/partner)
- 飞常准消费版 MCP 支持查航班动态、关注航班和读取已授权的未来行程。收费和状态覆盖待确认。[飞常准工具文档](https://cmcp.variflight.com/zh/tools/)
- 飞友 Aviation MCP 支持按路线或航班号查询，按次计费。官方文档列出新用户 50 元体验额度。[Aviation MCP 文档](https://ai.variflight.com/zh/docs/aviation)
- FlyClaw 是免 Key 的开源聚合工具，可作为查票候选。[FlyClaw](https://github.com/AI4XE/FlyClaw)
- 飞常准 DataWorks 有包含登机状态字段的推送接口，可作为动态提醒候选。[DataWorks 推送文档](https://dataworks.variflight.com/about-us/download-zone/flight-status-subscription-push-api/)

接手时再确认首版范围、实际免费额度、登机状态覆盖，以及自动导入和 QQ 动态提醒的接入条件。
