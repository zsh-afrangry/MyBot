# 月度邮件账单导入与多格式读取

## 功能

- 从邮件附件、QQ 上传或本机受控目录批量导入 XLSX 账单到 KnowledgeMap。文件获取和读取见[邮件附件](20_邮件能力与横切扩展.md#接口)、[QQ 文件落地](32_QQ渠道与SnowLuma.md#主人私聊文件落地工作区)及[结构化读取](37_编码委托扩展与受控电脑管理.md#kurumi_files-与-kurumi_lease)。
- 主人确认前可核对原文件名、日期范围、金额、各文件新增与跳过、拟建分类及同日同额的手工账单提示。哈希和暂存路径留在内部。文件内容相同才提示对应文件序号。

## 接口

| `knowledge_bill_import` 动作 | 用法 |
| --- | --- |
| `preview` | 单份传绝对路径 `path` 和可选 `sheet`。多份传按导入顺序排列的 `files:[{path,sheet?}]`，每组 2～8 份。单份或整组合计最多 5000 条有效记录，生成一份提案。 |
| `commit` | 取得 `bills_import` 域授权后传 `proposalId`，按预览顺序提交并逐份返回结果。[二次确认规则](6_二次确认.md) |
| `status` / `batches` | `status` 按原 `proposalId` 回查未知结果，`batches` 查询最近的导入批次。 |

## 原理

- 预览按顺序计算文件间和账本已有的重复条目，冻结文件内容和导入计划。文件或计划变化时重新预览。KnowledgeMap 在同一事务内创建缺失的分类和小类、写入整组账单并保存回执。
- 导入行指纹由东八区秒级时间、收支类型、金额、分类、小类、备注及相同组合的出现序号生成，作为 `assistant_bill_origins` 的唯一来源键。

## 限制与已知问题

- 生产按单份确认导入。多文件一次确认需加载 Fusion 和 KnowledgeMap 新版服务。
- 账单 XLSX 使用固定 6 列（`账单日期`、`分类筛选`、`记账分类`、`收支类型`、`备注`、`金额`）。
