# 月度邮件账单导入与多格式读取

打通“邮箱收信/QQ 传文件/本地工作区 → 结构化读取与账单批预览 → 主人二次确认 → KnowledgeMap 幂等落库”的月度记账闭环，并补齐常见办公文档受控读取及邮箱收件箱治理能力。

## 功能

- **全渠道文件落地与多格式读取**：沿用[文档37](37_编码委托扩展与受控电脑管理.md)分级文件边界，为 `kurumi_files` 增加 `read_structured`（`csv`/`tsv`/`xlsx`/`docx` 分页只读解析，自动还原 Excel 东八区日期序列号），并支持主人通过 QQ 私聊上传非 PDF 办公文件至默认工作区 `qq-inbox/`；成员入口仍严格限 PDF（[文档32](32_QQ渠道与SnowLuma.md)）。
- **月度账单 `.xlsx` 批量导入**：在[文档23](23_KnowledgeMap业务能力桥接.md)共享账单能力上新增 `knowledge_bill_import` 与 KnowledgeMap 批量接口，按单行确定性指纹防重、动态识别未知分类并在单一事务内建标签与写账单，导入前提示同日同金额手工账单重叠。
- **邮箱收件箱管理与双层发件人白名单**：在[文档20](20_邮件能力与横切扩展.md)上扩展受控 IMAP4rev1 客户端 `email_inbox`（默认 `1794511189@qq.com` `imap.qq.com:993`，预留多账号扩展字段）。对非长期白名单或认证告警邮件默认只返回不可信元数据摘要，读取正文与下载附件须经主人二次确认当场放行，删除仅移入已删除文件夹（不做物理 `EXPUNGE`）。
- **权限、管理台、日志与验收联动**：权限词汇、发件人白名单 `mailSenders` 与 `kurumi_access(mail_sender)` 归[文档24](24_统一身份与权限管理.md)；管理台白名单联动归[文档33](33_Fusion后端Web界面.md)；链路旁路日志归[文档18](18_跨模块链路日志查询.md)；全自动隔离场景归[文档36](36_通用场景验收.md)。

## 原理

- **入口与处理解耦**：邮件附件落地 `kurumi-space/mail-attachments/`、主人 QQ 办公文件落地 `kurumi-space/qq-inbox/`、本机受控文件保留原路径，统一经 `T0/T1/T2/T3` 路径校验进入通用读取与账单导入工具。
- **双层确认闸门**：账单批量导入（`bills_import` 域）冻结文件 SHA256、`preview_hash` 与拟建新标签；陌生发件人读信/下附件及删移邮件（`mail_inbox` 域）冻结 `uidValidity` 与原文摘要，均走 `@kurumi/confirmation-core` 单次授权并在提交前复核未漂移。
- **防重与抗注入**：导入表以 `xlsx-v1:sha256(东八区秒级时间|收支类型|金额|分类|小类|备注|同秒序号)` 作为 `assistant_bill_origins` 唯一来源键，与手工 `bills` 隔离；邮件头/正文/文件名加不可信边界与 `Authentication-Results` 降级校验。
