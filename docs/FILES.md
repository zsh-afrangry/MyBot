- 新增 `docs/` 顶层文件时，在本页对应分组登记用途；规则文档编号继续用 9 起递增，历史文件保持原编号。
- 移动或归档文件后，检查**正文中的路径引用**（不只是 Markdown 链接）——至少
  `grep -rn "<文件名>" docs scripts chatbot config roles`。
- 历史文件只加标记与指针，不改写原始记录；确需更正时写"已于 <日期> 作废"并保留原句。
