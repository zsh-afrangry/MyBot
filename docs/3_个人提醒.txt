摘要
----

这是一个只面向主人 QQ 私聊的一次性提醒模块。模型只能提交严格类型的 proposal，主人在同一私聊
明确确认后，后端才会通过受限 Cron adapter 注册或修改任务；到点由固定 CLI 投递，不重新唤起模型。
群聊永久关闭，通用 Cron/QQ 发送/任意收件人/任意 payload 均未开放。提醒状态和审计在独立 SQLite 中保存，
但历史终态不会通过 `state_get` 注入模型上下文。

二、当前能力与安全边界
======================================================================

- 仅主人 QQ 私聊可用；身份由 QQ 元数据和 allowlist 判定，正文自称主人无效。
- `channels.qqbot.groupPolicy=disabled`；工具层群聊 deny 作为纵深防御。
- `Asia/Shanghai` 明确本地时间，至少提前 1 分钟、最多 366 天；内容 1–200 字；一次性提醒。
- 模型不能传收件人、Cron、命令、URL、job ID 或任意 payload；目标由可信私聊上下文注入。
- 原生 `qqbot_remind` 和通用 `cron` 不开放；到点使用固定 command CLI，不调用模型。
- `unknown`/`scheduling`/投递结果无法证明时，状态给主人可见；不猜测、不重发、不取消、不继续修改。
- 只有明确 delivery failure 才进入受控 retry，最多 3 次总尝试；unknown 不自动重试。

状态机：

  reminder.status: `scheduling` -> `scheduled` -> `delivering` -> `delivered`
       \\-> `failed` / `cancelled`

  retry_status: `scheduling` / `scheduled` / `pending` / `delivered` / `cancelled` /
                `exhausted` / `unknown`

======================================================================
三、提案与原地修改协议
======================================================================

创建：`personal_reminder_propose` 生成 `reminder.create` pending 预览；只有同一私聊明确确认后，
`personal_reminder_commit` 才注册受管 Cron。

取消：`personal_reminder_cancel_propose` -> `personal_reminder_cancel_commit`，只引用既有提醒 ID；
删除 Cron 失败时不修改本地取消状态。

修改：`personal_reminder_change_propose` 绑定状态为 scheduled、retry 为 scheduled 且有受管 Cron 的提醒，
展示旧/新时间和内容，并声明“原地更新、不创建第二条任务”。commit 流程：

1. 复核 proposal TTL、payload hash、私聊上下文、旧内容/时间/job ID 和 retry 状态。
2. 事务保存新本地期望值并写 `reminder.update_requested` 审计。
3. 只改内容时不访问 Gateway；改时间时只调用
   `cron.update({id: oldJobId, patch:{schedule:{kind:"at",at:<new UTC ISO>}}})`。
4. 成功且本地确认成功才恢复 scheduled；异常或响应丢失写 `cron_update_unknown`，返回
   `update_unknown`，阻断后续修改/取消/重发；重复 commit 不再次调用 Gateway。

这不是 SQLite 与 Gateway 的真正原子事务；设计选择是结果不确定时停住，避免重复注册、错时提醒或
用“取消旧提醒 + 新建提醒”掩盖未知状态。

======================================================================
四、实现路径与数据
======================================================================

- `chatbot/plugins/personal-weather/src/index.ts`：工具声明、主人私聊守卫、受限 scheduler。
- `src/reminders.ts`：输入解析、proposal、commit、状态策略和修改协议。
- `src/reminder-store.ts`：SQLite schema/事务/审计/retry/unknown 闸门。
- `src/reminder-gateway.ts`：固定 `cron.add/update` 参数构造。
- `src/reminder-cli.ts`：到点 claim 和固定中文投递文本，不调用模型。
- `src/reminder-reconciler.ts`、`src/reminder-reconciler-service.ts`：只读对账、60 秒扫描和有限重试。
- `chatbot/skills/personal-weather/SKILL.md`：何时提案、确认和不落库规则。
- `state/personal-reminders/reminders.sqlite`：独立提醒库，目录 0700、数据库 0600。

核心表：`reminders`、`reminder_proposals`、`reminder_retry_state`、`reminder_audit_log`。
`state_get` 只选活动状态；终态、提案历史和审计不作为工具结果返回，因此不会因数据库保留自动进入模型上下文。
