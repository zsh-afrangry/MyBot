## 实现与机制验证

`proactive-core/lifecycle.js`只消费经过验证的主体、Agent/会话、消息ID、事件类型和平台时间；QQ真实入站处理器在身份、持久去重、路由核对之后、附件/引用I/O及模型之前提供可选回调。正文、引用、文件名和历史均不进入观察器或执行账本。未装配回调时原有生产入口不创建N3状态。

`authority.invalidate`先持久撤销旧代际，再中止当前进程中的活跃运行。新消息可以立即结束不配合取消的模型等待；迟到的旧输出仍被执行层拒绝。真实OneBot的新鲜平台时刻才可更新活动；旧/缺失/未来时刻只撤销，乱序不回拨，离线文件notice和合成入口不制造在线依据。reset/end按固定主人会话撤销，保留暂停、记忆及既有账本。

投递准备中断保持unknown，不意味着实际撤回。实际发送的迟到回执可在运行凭据释放后通过专用结果闭包记实；该闭包不能执行工具、再发消息或取得下一次授权，同事件继续拒绝重放。
