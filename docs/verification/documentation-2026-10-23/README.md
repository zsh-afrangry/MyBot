## 文档—代码核对

本轮重点复核三模块及记忆生命周期，入口见[文档25第2节](../../25_人格、记忆与会话连续性.md#2-已核实的现状)。[代码定位记录](code-correspondence.json)保存源码路径、函数/常量和SHA256，不含运行私密内容。

- 四份人格投影由受管来源生成，不能将仓库docs或任意Markdown当每回合自动输入。
- 固定宿主默认bootstrap候选为AGENTS/SOUL/IDENTITY/USER/BOOTSTRAP/MEMORY，按会话类型/文件存在性/预算过滤；TOOLS常量存在不等于在默认表内。
- 自动注入是当前RawBody绑定的prompt钩子；显式search为规范化子串查询，context为词片段排序及字符预算，当前无向量检索。
- observe/upsert/delete通过工具与SQLite事务落库；agent_end/reset/end负责许可失效，不做事后全历史自动提炼。旧会话与当前有效记忆是不同数据。
- `sessions_list/history`有权限映射，`sessions_search`未登记；不将模型调用失败当成全会话搜索已实现。

这些是代码核对结论，不是本轮真实模型调用或长期陪伴验收。
