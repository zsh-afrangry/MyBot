### 制作与验证恢复点

以下操作按实际授权执行；文档整理不自动运行停写/恢复。

```bash
node scripts/fusion/backup-state.mjs --label rollback --quiesce
node scripts/fusion/restore-verify.mjs --backup /home/afrangry/kurumi-backups/<具体目录>
```

- `--quiesce`检查稳定状态，只停止原本运行的Fusion；完成、异常或可捕获中断后恢复，原本停止则保持。它只表示受管服务已停写，期间不能另起Gateway或手工编辑状态；在线快照只保证单库一致。
- 采集先写`INCOMPLETE.json`并持有`.backup.lock`，收集成功且恢复服务后才移除标记。SIGKILL/断电不可捕获：确认锁中PID已消失、检查并必要时恢复服务，再处理陈旧锁；不得删除不完整标记伪装成功。生产SIGTERM演练退出143、服务恢复和不完整拒绝的证据按最终恢复报告保留。
- 已跟踪修改用Git `--binary --full-index`补丁，未跟踪非忽略文件单独tar；不保留原暂存区分类，不承诺源码侧所有忽略文件。旧系统全量包和固定SDK是独立材料，新备份不重复包含。默认要求`EXPECTED.json`，旧pre-consolidation不直接当新格式恢复点。

### 隔离恢复模式

`restore-verify.mjs`仅接受新建规范`/tmp/`目标，拒绝已有目录/链接，不覆盖生产或操作主机服务。先验manifest/仓库/数据库，再固定SHA256恢复OpenClaw 2026.9.7 SDK及锁定依赖，沙箱内构建/实际加载插件、启动Gateway及模拟OneBot，执行项目检查。可用`--sdk-archive`指定复制到本机的固定包，不借用全局已安装SDK。

恢复器改写workspace/token/日志/runner/项目root与fixture等路径，写入假凭据，禁真实QQ、Cron和共享业务API；不改历史聊天原文。Bubblewrap隔离文件系统/网络/PID，生产home和服务总线不可见，固定SDK路径只读映射归档。探针结束关闭模拟频道，层级记录在`verification.json`与`isolation-result.json`。

`--skip-deps`仅为材料检查；默认通过表示隔离Gateway+模拟传输可运行，均不证明真实模型/API/QQ登录恢复。**不得在主机直接运行恢复副本的run-gateway.mjs**；隔离启动只走内部探针。正式灾难恢复应停机后按原路径恢复原配置/凭据、单独处理调度和重复投递对账，不用测试凭据副本代替原始备份。旧A/B只按文档15显式选择并复制，不自动启动。
